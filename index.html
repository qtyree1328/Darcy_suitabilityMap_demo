Methodology

Iowa Geothermal Suitability Assessment — Technical Methods

Overview

This map presents a multi-criteria geothermal suitability assessment for the state of Iowa, computed at 30-meter resolution using Google Earth Engine. The model evaluates six geospatial factors weighted by their relevance to ground-source heat pump (GSHP) and shallow geothermal system feasibility. The final score (0–100) is a weighted linear combination of normalized factor scores.

Processing

All raster analysis was performed in Google Earth Engine using the Python API. The suitability overlay was rendered as a color-mapped PNG at 2048px width and georeferenced to Iowa's bounding box. Histogram equalization (p2–p98) stretches the value range for visual contrast. Vector layers (wells, aquifers, EPA sites) are served as GeoJSON for client-side rendering.

Suitability Factors

FactorWeightSourceScoring
Aquifer Quality35% USGS Principal Aquifers Scored by aquifer type: Cambrian-Ordovician = 1.0, Silurian-Devonian = 0.9, Upper Carbonate = 0.8, Mississippian = 0.6, Lower Cretaceous = 0.5, Other Rocks = 0.1
Well Density20% USGS NWIS Kernel density (5 km radius), unitScale 0–1. Higher density = more productive aquifer zone.
Bedrock Geology12% Fallback: uniform 0.4 Iowa is generally favorable for geothermal. With bedrock data: limestone/dolomite = 1.0, sandstone = 0.9, crystalline = 0.8, shale = 0.6.
Land Cover12% NLCD 2021 (GEE native) Grassland = 1.0, agriculture = 0.9, forest = 0.8, suburban = 0.5, urban = 0.3, water = 0.
Environmental Constraints10% NLCD wetlands + EPA NPL Wetland/water = 0; Superfund sites (500m buffer) = 0; elsewhere = 1.0.
Hydrologic Proximity11% NLCD water/wetland + GEE fastDistanceTransform 0–250m = 1.0, 250–1000m = 0.8, 1000–2500m = 0.5, 2500–5000m = 0.2, >5000m = 0. Proximity to water indicates shallow groundwater access.

Suitability Equation

Score = 0.35 × AquiferQuality
       + 0.20 × WellDensity
       + 0.12 × Geology
       + 0.12 × LandCover
       + 0.10 × Constraints
       + 0.11 × HydroProximity

Output: 0–100 (each factor normalized 0–1, then scaled)

Color Ramp

The map overlay uses histogram equalization (p2–p98) to stretch the actual data distribution across the full color palette. This maximizes visual contrast without changing the underlying data.

Site Inquiry (Click Report)

Clicking any location in Iowa generates a site inquiry report. The overall score is a weighted sum of six factor scores computed client-side from loaded vector data (aquifer type, well proximity, EPA buffers) and geographic proxies for geology and land cover. These are approximate and intended for rapid screening, not engineering decisions.

Limitations

  • Bedrock geology uses a uniform fallback (0.4) due to lack of a statewide geology raster.
  • Well density reflects USGS-monitored sites only, not all private wells.
  • Flood zone data (FEMA) and NWI wetlands are proxied by NLCD classes 90/95.
  • This is a screening tool. Site-specific geotechnical investigation is required before installation.
